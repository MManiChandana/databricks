# PulseCart

## E-Commerce Data Intelligence Platform

> From raw transactions to real-time business decisions.

PulseCart is an end-to-end data engineering and analytics platform built using Databricks, PySpark, SQL, Delta Lake, and Power BI.

The project demonstrates how raw e-commerce data can be transformed into reliable, business-ready intelligence using a modern data engineering architecture.

## Technology Stack

- Databricks
- PySpark
- Python
- SQL
- Delta Lake
- Databricks Workflows
- GitHub
- Power BI

## Architecture

PulseCart follows the Medallion Architecture:

**Raw → Bronze → Silver → Gold → Business Intelligence**

## Business Intelligence

The platform will provide:

- Revenue Intelligence
- Customer Intelligence
- Product Intelligence
- Order Analytics
- Data Quality Monitoring
- Pipeline Monitoring

## Project Goals

- Build an end-to-end ETL pipeline
- Implement Delta Lake
- Apply PySpark transformations
- Implement data-quality checks
- Create business-ready Gold datasets
- Automate the pipeline
- Integrate GitHub version control
- Build analytical dashboards
